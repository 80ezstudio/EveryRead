# Every Read public pages

This repository contains only the public support and legal pages for Every Read. App source, build information, release artifacts, credentials, signing material and internal documentation are maintained separately in a private repository.

## Published pages

- `index.html`
- `privacy-policy.html`
- `terms-and-conditions.html`
- `credits.html`
- `delete-account/index.html`

## Publishing

GitHub Pages is published from the root of the `main` branch. Public URLs use the base `https://80ezstudio.github.io/EveryRead/`.

Before publishing a change, verify that each page renders correctly, all internal links use the Every Read Pages base URL, and the page displays a **Last updated** date without a document version or effective-date label.
